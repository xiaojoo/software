# 管理后台、评论审核与软件截图设计

日期：2026-10-26

## 目标

为现有软件目录站增加受账号密码保护的管理后台。管理员能够浏览并管理用户评论，并为各软件维护多张截图。软件详情页在版本下载区域之后按顺序纵向展示截图；某软件没有截图时，不渲染截图区域。

现有公开评论提交和 GitHub 版本信息继续沿用。访客提交的评论继续即时公开，管理员可隐藏、恢复或永久删除评论。评论隐藏后，不出现在公开评论列表中，也不计入软件公开的评论数和平均评分。

## 技术方案

保留原生 HTML、CSS、JavaScript Web Components 和 Cloudflare Pages Functions。Pages Functions 继续提供同源 API，Cloudflare D1 保存评论状态和截图元数据，新增 Cloudflare R2 bucket 保存图片文件。R2 对象不开放匿名 bucket 访问；公开页面通过一个只读媒体路由读取并返回允许的图片格式。

后台是单管理员账户，不增加用户注册或角色系统。用户名、密码和会话签名密钥只通过 Cloudflare Secrets / 本地 Wrangler secrets 配置，不能写入源码或 D1。登录成功后设置带签名、过期时间的 `HttpOnly`、`Secure`、`SameSite=Strict` Cookie。后台 API 对所有管理操作验证会话；状态变更还校验同源请求。登出清除 Cookie。

## 页面和交互

1. **后台登录**：`/admin/` 登录页，提供用户名、密码输入和登录错误提示。登录成功进入管理界面；会话无效或过期时回到登录页。
2. **评论管理**：按软件筛选评论，显示评分、内容、提交时间和当前状态。每条评论可隐藏、恢复或永久删除。隐藏操作可撤销，删除操作需二次确认。
3. **截图管理**：按软件选择产品，上传多张 PNG、JPEG 或 WebP 图片；显示预览及上下移动、删除操作。上传顺序为前台显示顺序。单图大小上限为 10 MiB；后端校验 MIME、文件签名和大小。
4. **前台展示**：软件详情的版本下载展示区之后出现“软件截图”部分，按管理顺序纵向展示，图片自适应内容宽度。若查询结果为空或数据 API 不可用，不显示该部分，不影响下载信息和评论区。

## 数据与 API

新增 D1 迁移：

- 在 `reviews` 增加 `is_hidden`（默认 `0`），保留已有评论的公开状态。
- 新增 `software_screenshots` 表，保存截图 ID、软件 ID、R2 object key、MIME、字节数、排序位置、待删除标记和创建时间，并为软件 ID 和排序位置建立索引。

管理 API 按 `/api/admin/*` 组织：登录、登出和当前会话读取；评论列表、隐藏状态更新、删除；截图列表、上传、排序和删除。所有评论和截图管理路由均要求有效管理员会话。公开评论 API 只返回未隐藏的评论，公开聚合数据也只统计未隐藏评论。

截图上传时先验证管理员会话、软件 ID、文件类型、文件签名和大小，再写入 R2，最后写入 D1 元数据。元数据写入失败时清理刚上传的 R2 对象。删除使用 D1 的软删除标记：先将图片设为待删除并立即从公开列表排除，再删除 R2 对象，成功后移除 D1 记录。若 R2 清理失败，后台保留待清理记录供管理员重试，前台不再展示该图。R2 对象通过 `/media/{key}` 读取，只允许已登记且未删除截图对应的 key 和支持的图片 MIME，响应使用正确的 `Content-Type`、`X-Content-Type-Options: nosniff` 与可缓存策略。

## 配置与部署

在 `wrangler.toml` 为生产和本地配置 R2 binding（例如 `SCREENSHOTS`），并在 Cloudflare 创建 bucket。需要设置 `ADMIN_USERNAME`、`ADMIN_PASSWORD`、`ADMIN_SESSION_SECRET` secrets；本地开发通过 `.dev.vars` 提供值，文件保持在 `.gitignore` 中。README 增加 bucket 创建、绑定、secrets 配置和本地 D1 迁移步骤。

现有 `npm run dev` 从 `dist` 提供静态文件。后台入口及其 CSS/JS 需要通过现有静态资源发布目录提供，并保持源码目录结构清晰；实现时补充最小的同步/构建步骤，保证本地预览和 Wrangler 部署都包含 `/admin/` 文件。

## 安全与错误处理

- 密码不写入数据库、HTML、前端脚本或日志；会话签名失败、过期、缺少密钥或缺少账号配置时管理 API 默认拒绝访问。
- 所有用户可见文本通过 DOM `textContent` 或现有的 HTML 转义规则渲染；不能将上传文件名或评论 HTML 作为可信内容。
- 上传限制文件大小和允许的栅格格式；拒绝 SVG 及其他主动内容格式。
- D1/R2 不可用时，管理接口返回明确的非 2xx 错误；公开页面继续展示其他可用内容。
- 删除截图时保持 D1 与 R2 最终一致，并向后台返回清晰的清理状态，避免产生前台失效图片记录。

## 范围与验收

- `/admin/` 可登录、登出；未登录不能读取或修改管理数据。
- 评论可按软件查看、隐藏、恢复和删除；隐藏评论从公开列表与统计中消失，恢复后重新计入。
- 管理员可上传每款软件多张截图并调整顺序；只接受受限图片类型和大小。
- 前台纵向显示软件截图，且无截图时整个截图模块不存在。
- 本地 Wrangler 和 Cloudflare Pages 的目录、D1、R2 与 secrets 配置步骤在 README 中有说明。
- 不实现多管理员、访客账号、评论回复、富文本后台编辑、批量导入、图片裁剪或轮播。
