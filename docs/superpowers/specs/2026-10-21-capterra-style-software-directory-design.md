# Capterra 风格软件目录页设计

日期：2026-10-21

## 目标

在当前空工作区中创建一个可直接在现代浏览器运行的单页网站，视觉上贴近用户提供的 Capterra 截图：白色背景、深色文字、品牌蓝色按钮、细边框圆角卡片、紧凑的信息层级。页面需要使用弹性和动态布局，在桌面、平板和手机宽度下自然重排。

截图仅作为视觉与内容参考。页面中的搜索、分类切换和表单采用前端演示交互，不连接真实账户、搜索服务或后端。

## 技术方案

采用原生 HTML、CSS 和现代 JavaScript（ES modules）。不引入框架或构建依赖，以降低空项目启动成本。通过语义化 HTML 表达结构，JavaScript 负责组件渲染与少量交互，CSS Grid、Flexbox、`clamp()`、相对单位和媒体查询负责响应式布局。

组件以原生 Web Components（自定义元素）实现，按页面区域拆分；每个组件拥有明确的标签与职责，使用共享 CSS 设计 token 保持视觉一致。产品内容放在 JavaScript 数据数组中，由分类和比较组件复用。

## 页面组成

1. **站点导航**：品牌标识、搜索入口、分类/比较/研究链接、供应商入口和登录按钮；窄屏折叠为简洁导航。
2. **搜索主视觉**：浅蓝几何背景、主标题、副标题、搜索框和统计信息。提交搜索显示本地演示反馈。
3. **热门分类**：分类标签与软件产品卡片。卡片包含名称、评分、评论数、简要推荐语、情绪条和操作按钮。分类切换更新展示的产品。
4. **个性化建议横条**：简短文案和获取建议按钮。
5. **热门产品比较**：产品摘要、关键指标和横向比较布局；小屏转为可横向滚动区域。
6. **选购指南与电子书表单**：指南标题、说明、步骤列表和邮箱表单；前端完成邮箱格式校验并显示提交成功反馈。
7. **用户评价与媒体背书**：介绍文案、评价卡片轮播控件及媒体名称展示。
8. **双推广卡片**：供应商和软件用户入口，使用蓝色渐变/几何装饰呼应截图。

## 组件边界

- `site-header`：导航和移动端菜单。
- `hero-search`：搜索标题、输入与演示反馈。
- `category-explorer`：分类选项和产品集合的筛选状态。
- `software-card`：单个产品的评分、情绪条和操作入口。
- `comparison-section`：比较对象、指标卡片和横向滚动容器。
- `buying-guide`：指南文案、步骤和邮箱表单反馈。
- `testimonial-section`：评价内容与上一条/下一条切换。
- `promo-grid`：底部推广卡片。

各组件通过属性或自定义事件交换必要状态；不引入全局状态库。产品数据由页面入口模块集中定义并传给相关组件。

## 响应式与视觉规则

- 内容区设置最大宽度并使用流体侧边距。
- 大屏产品卡片采用三列 Grid；中屏两列；手机单列。
- 比较区在窄屏保留可触控横向滚动，其他内容不产生横向溢出。
- 导航、标题、间距和卡片内边距根据视口缩放；交互目标保持易点击。
- 字体优先使用系统无衬线字体栈，减少外部字体依赖；颜色、边框、圆角、阴影通过 CSS 自定义属性统一维护。
- 提供清晰焦点样式、表单标签和语义化按钮；尊重 `prefers-reduced-motion`。

## 文件组织

- `index.html`：页面入口、SEO 基础信息和组件挂载点。
- `styles/tokens.css`：颜色、字体、圆角、间距和阴影变量。
- `styles/main.css`：全局、响应式布局和组件样式。
- `src/main.js`：页面数据与组件装配。
- `src/components/*.js`：原生 Web Components 实现。

在空工作区直接打开 `index.html` 即可运行；组件模块通过本地 ES module 加载。若浏览器对 `file://` 模块加载有限制，可用任意静态文件服务器预览，无需项目构建步骤。

## 范围与验收

交付重点是完整长页面、与参考图一致的视觉风格、组件化源码和响应式重排。所有按钮和表单至少有本地可见反馈；不实现真实登录、真实搜索、外部商品数据、账户系统或后端服务。代码完成后检查文件结构与关键页面行为，并在可用浏览器中查看桌面和窄屏布局。
